# Story 4.24: Favicon oficial do Cirne Rotas

## Status

**Done** — QA Gate PASS em 2026-11-06.

## Story

Como usuário do Cirne Rotas, quero reconhecer o símbolo oficial do produto na aba do navegador, para distinguir o sistema de páginas com ícone genérico.

## Acceptance Criteria

1. A metadata global declara um favicon do Cirne Rotas e o navegador não depende do ícone genérico.
2. O favicon reutiliza o símbolo presente no cabeçalho/login, com contraste legível em tamanho reduzido.
3. O manifesto PWA continua apontando para ícones válidos e coerentes com a mesma marca.
4. Testes automatizados cobrem a metadata/arquivo e lint, typecheck, testes e build passam.

## Tasks / Subtasks

- [x] T1 — Alinhar o ícone SVG do aplicativo ao símbolo oficial (AC: 2–3).
- [x] T2 — Declarar o favicon na metadata global (AC: 1).
- [x] T3 — Adicionar teste de regressão e executar gates (AC: 1–4).

## Dev Notes

- Reutilizar o desenho vetorial existente em `features/auth/brand.tsx`; não introduzir nova marca.
- Preferir SVG versionado no app e referência explícita na metadata do Next.js.

## Testing

- Executar `npm run lint`, `npm run typecheck`, `npm test` e `npm run build`.
