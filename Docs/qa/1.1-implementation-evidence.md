## Decisões e correções verificadas

- TypeScript 7.0.2 foi rejeitado pelo peer de typescript-eslint 8.70.0 (`<6.1.0`). Fixado 6.0.3, sem ignorar peers. React 19.3.0 compatível com Next 16.3.4.
- Refinamento Zod agora trata URL inválida sem lançar erro bruto/entrada. Configuração é privada e valores não aparecem em mensagem de erro.
- Supabase 2.117.0 publica `dist/supabase.js`, não o antigo `bin/supabase.exe`; comandos executam o shim pelo Node, sem shell. Um ensaio após reinstalação excedeu o timeout de 15s; limite de diagnóstico ajustado para 30s e suíte repetida com sucesso.
- Teste real revelou que uma rejeição simples do hook de instrumentação não encerra necessariamente o Next. Inicialização inválida agora registra erro controlado e encerra com código 1, em módulo restrito a Node.
- `next start` advertiu sobre standalone. O início nativo passou a executar o mesmo `server.js` standalone usado pelo container; assets são preparados no build e integração usa esse artefato.
- Supabase indicou depreciação de `[inbucket]`; configuração atualizada para `[local_smtp]`.
- Rede exclusiva identificada por label; scripts recusam contexto remoto/rede incompatível e divergência de project_id. Parada só usa o projeto próprio, sem `--all`/`--no-backup`. Persistência real comprovada com dado sintético e limpeza posterior.
- Rancher Desktop 1.24.0 foi configurado com Moby/dockerd e Kubernetes desativado. O diretório de CLI do Rancher foi incluído no PATH do usuário; novos terminais reconhecem `docker` e `docker compose`.
- O aviso de diagnóstico do Rancher sobre `~/.kube/config` ausente é irrelevante com Kubernetes desativado. O runtime Docker e a integração WSL responderam normalmente.
- AIOX aponta para PRD/arquitetura monolíticos e stories em `Docs/`. Caminhos de fallback inexistentes removidos; demais configurações preservadas. O gerador de greeting ainda apresentou referências internas antigas, sem mudança no framework fora do escopo.
- O primeiro índice Git trata este repositório como projeto consumidor do AIOX: o framework instalado em `.aiox-core/` e o cache `.aiox/` ficam locais; somente `.aiox-core/core-config.yaml` é versionado. Atributos Git fixam finais de linha reproduzíveis e identificam os artefatos binários.
- Nenhum recurso de negócio, dado real, envio externo, publicação ou dependência do n8n foi introduzido. Git local sem commit-base: reversão requer revisão por arquivo; não usar reset destrutivo.
